# LOKTHIEK.com - Comprehensive Interactive Web Features

A fully-featured, modern website demonstrating comprehensive interactive button types and UI components. Built with vanilla HTML, CSS, and JavaScript with no external dependencies.

## 🚀 Features

### Core Structure
- **Responsive Design**: Mobile-first approach with breakpoints for all screen sizes
- **Dark/Light Theme**: Toggle between themes with persistent storage
- **Semantic HTML**: Proper structure and accessibility features
- **Modern CSS**: CSS Grid, Flexbox, animations, and transitions
- **Vanilla JavaScript**: No framework dependencies, pure JavaScript

### Navigation & Layout
- ✅ Sticky navigation bar
- ✅ Responsive hamburger menu for mobile
- ✅ Smooth scrolling navigation
- ✅ Scroll-to-top button
- ✅ Theme toggle (dark/light mode)

### Interactive Components

#### Buttons & Controls
- **Primary/Secondary Buttons**: Standard action buttons with hover effects
- **Icon Buttons**: Buttons with icons and text
- **Filter Buttons**: Toggle-style buttons for filtering content
- **Loading Buttons**: Buttons with loading spinner states
- **Social Buttons**: Circular social media buttons

#### Form Elements
- **Contact Form**: Full form with validation and submission
- **Search Box**: Real-time search functionality
- **File Upload**: File selection and upload handling
- **Input Fields**: Text, email, textarea with proper styling

#### Content Display
- **Tabs Component**: Multi-tab interface with active states
- **Accordion**: Expandable/collapsible content sections
- **Image Carousel**: Auto-playing slider with navigation
- **Modal/Popup**: Overlay modals with backdrop
- **Toast Notifications**: Success, warning, and error notifications
- **Expand/Collapse**: Show more/less content toggle

#### Interactive Features
- **Dropdown Menus**: Click-to-open menus with options
- **Pagination**: Page navigation controls
- **Filter & Sort**: Content filtering and sorting buttons
- **Media Controls**: Play, pause, stop, previous, next buttons
- **Like/Share**: Social interaction buttons
- **Copy to Clipboard**: One-click text copying

#### Action Buttons
- **Download**: File download functionality
- **Upload**: File selection and upload
- **Print**: Browser print dialog
- **Export**: Data export (CSV format)
- **Import**: Data import functionality
- **Search**: Search with real-time feedback

### Advanced Features
- **Keyboard Shortcuts**: Ctrl/Cmd+K for search, ESC for modals
- **Auto-play Carousel**: 5-second interval slide changes
- **Local Storage**: Theme preference persistence
- **Smooth Animations**: CSS transitions and keyframe animations
- **Click Outside Detection**: Auto-close dropdowns and modals
- **Responsive Grid Layouts**: Dynamic column adjustments

## 💡 Usage Examples

### Theme Toggle
- Click the moon/sun icon in the navigation bar
- Theme preference is saved in localStorage

### Interactive Components
- **Tabs**: Click tab buttons to switch content
- **Accordion**: Click headers to expand/collapse
- **Carousel**: Use arrow buttons or auto-play
- **Modal**: Click "Get Started" to open modal

### Notifications
- Click notification buttons to see toast messages
- Toasts auto-dismiss after 5 seconds
- Manual close button available

### Form Submission
- Fill out the contact form
- Submit to see success notification
- Reset button clears all fields

## 🔧 Customization

### Colors
Edit CSS variables in `styles.css`:
```css
:root {
    --primary-color: #2563eb;
    --secondary-color: #64748b;
    /* ... more variables */
}
```

### Content
Modify HTML in `index.html` to change:
- Text content
- Section order
- Number of components

### Functionality
Extend JavaScript in `script.js`:
- Add new interactive features
- Modify existing behavior
- Integrate with backend APIs
